Lámina 1 · El modelo

Finpro conoce sus Cuentas; sus usuarios son suyos

Usted puede tener varios CVUs y cada uno corresponde a una única CVU/Cuenta Finpro. Sus clientes y usuarios finales los gestiona usted, no Finpro.

Para desarrollo

Finpro no tiene la entidad «usuario final». Cada CVU/Cuenta Finpro se identifica por su CVU/CBU y por un ID interno de Finpro; la relación entre sus usuarios y sus CVUs la mantiene su sistema.

Lámina 2 · Credenciales

Las credenciales van por Cliente API, no por cuenta

Cada cuenta que opera por API pertenece a un Cliente API. Todas las cuentas de ese Cliente API comparten la misma API Key, el mismo API Secret y la misma configuración de avisos. Si una cuenta necesita una configuración distinta, se crea otro Cliente API. Las cuentas sin Cliente API funcionan igual desde el portal web.

Cliente Finpro portal web

Es su empresa en Finpro. Puede tener N cuentas y ve todas.

Cliente API integración

Agrupa 1 o N de esas cuentas bajo una API Key + API Secret y una configuración de avisos. Con esas credenciales solo se ven y operan las cuentas asociadas.

Para desarrollo

Un Cliente API tiene un único par API Key + API Secret y una única configuración de webhooks, que aplican a todas sus cuentas asociadas. Una cuenta pertenece como máximo a un Cliente API; con esas credenciales solo se listan y operan esas cuentas. Para una configuración distinta en un CVU, se crea otro Cliente API.

Lámina 3 · Acciones

Su sistema actúa sobre cada cuenta

Su sistema opera con las credenciales del Cliente API e indica sobre qué cuenta actúa. Solo puede operar las cuentas asociadas a ese Cliente API; para las de otro Cliente API usa las credenciales de ese otro.

Para desarrollo

Cada llamada usa el par API Key + API Secret del Cliente API e indica la cuenta por CVU/CBU o ID interno. Con esas credenciales solo se listan y operan las cuentas asociadas a ese Cliente API; no hay una credencial que alcance a todas las cuentas del Cliente Finpro.

Lámina 4 · Avisos

Finpro le avisa cuando se mueve el dinero

Cuando entra o sale una transferencia de una cuenta, Finpro le avisa a la dirección configurada en su Cliente API, aunque usted no haya hecho nada. Si no hay dirección configurada, el aviso no se envía, pero la transferencia queda en el portal.

Para desarrollo

Las notificaciones salen hacia dos URLs separadas que usted configura por Cliente API, una para transferencias entrantes y otra para salientes, y aplican a todas sus cuentas asociadas. Cada aviso identifica la cuenta por CVU/CBU y por ID interno.

Lámina 5 · Datos

Guardamos la transferencia, no a la persona

De cada transferencia, Finpro conserva lo que figura en ella. No arma una ficha de quien transfirió: solo queda lo que trae la transferencia.

  • CVU/CBU origen y destino
  • titular tal como figura
  • CUIT/CUIL
  • importe
  • fecha
  • concepto / referencia
Para desarrollo

Por cada transferencia se registran los datos que figuran en ella y no otros datos de la persona que transfiere. Esos mismos datos viajan en el aviso, y desde su recepción la custodia es suya.
